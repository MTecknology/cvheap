CV Heap Data
============

This private repository was created by [CV Heap](https://cvheap.net/),
the first time information was submitted on the ["Job History" page](
https://search.cvheap.net/history).

## Edit Data

Content in this repository is intended to be modified using the [CV Heap Job
Editor page](https://cvheap.net/), but any other editor is perfectly fine.

**Important Reminders:**

- EVERYTHING should be included, from boring daily tasks to heroic recoveries

## Shared Data

This is the data that you shared with **CV Heap**; if/when you delete your
account and/or revoke the github app, we lose access. We do not use this data
for any purpose other than building a comprehensive score card. All scorecard,
search criteria, and other database information is keyed off your user and
deleted the moment your account is deleted.

## Privacy Policy

CV Heap does not, has never, and will never sell your data.

Review our [Terms of Service](https://cvheap.net/terms) to learn more.


## Data Usage

CV Heap matches your whole career against every job in the database, instead
of keyword-scanning a one-page summary. Both CV and JD (Job Description) are
sent through the same rigorous scoring system, allowing us to match candidates
on actual day-to-day life in the role, rather than a recruiting advertisement.
